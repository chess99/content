# 图片方案

## 最少张数

4 张。

第 1 张用意外判断制造停留，猫猫老师只作为标题旁的小视觉签名。后面三张直接使用真实截图，依次展示项目配置、十年日记资料和实际分析回复。不再制作拼贴图、关系图或概念说明图。

## 第 1 张

### 唯一任务

让陌生读者先看见并记住标题，同时对贴在文字边上的猫产生一点好奇。

### 逐字文案

ChatGPT 现在可能

比我自己还了解我了

### 方向 A

标题左对齐、两行同字号同字重，占据画面的主要视觉面积。猫猫老师变成趴在标题边缘的小挂件，轻微倾斜，只露出猫、垂下的爪子和弯起的橙色尾尖。

### 方向 B

标题居中铺开，小猫从第二行末尾探出，不增加其他图形。

### 选择

选择方向 A。标题是绝对主体，小猫依附在第二行文字的下缘，不再单独占据一个区域。左对齐的大字在缩略图下更容易扫读，挂件式小猫也比完整 Logo 更像一个可以长期变化的角色。

### IP 形象

长期母题仍是一只猫穿过聊天框，橙色尾尖作为识别点。封面这次不完整展示母标，而是使用一个更轻的角色变体：黑猫趴在文字边缘，两只爪子垂下来，尾巴向上弯起。它保留炭黑轮廓、橙色耳朵和尾尖，但不再承担解释概念的任务。

### 删除测试

删除后，整篇会失去最强的停留理由，也没有猫猫老师第一次正式出现的视觉形象。

## 统一视觉约束

- 第 1 张为 1080×1440，3:4。
- 第 2 至 4 张保留用户原始截图尺寸与界面，不生成或复刻 ChatGPT UI。
- 封面不加入答案、方法清单、作者名、Logo、页码或系列名。
- IP 形象避免机器人、芯片、霓虹蓝、博士帽、眼镜、书本和普通猫爪 Logo。
- 270×360 缩略图下，封面可以完整读出标题；小猫只需看出猫、垂爪和橙色尾尖，不要求读出完整母标。
- 发布前由用户再次确认截图侧栏、账号名称与其他任务名是否可以公开。
