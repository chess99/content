# 图片方案

## 最少张数

4 张。

第 1 张用意外判断制造停留，标题与猫猫老师由图片模型作为一张完整画面共同生成。后面三张直接使用真实截图，依次展示项目配置、十年日记资料和实际分析回复。不再制作拼贴图、关系图或概念说明图。

## 第 1 张

### 唯一任务

让陌生读者先看见并记住标题，同时对贴在文字边上的猫产生一点好奇。

### 逐字文案

ChatGPT 现在可能

比我自己还了解我了

### 方向 A

标题左对齐、两行同字号同字重，占据画面的主要视觉面积。猫猫老师趴在第一行左上方，身体压在文字上沿，两只爪子自然垂到字面前方，猫与标题由模型整图生成。

### 方向 B

标题保持居中，小猫缩到左下角并趴在画面底部，身体由地面支撑，不接触标题。

### 选择

选择方向 A。猫的趴姿天然需要支撑，让它直接趴在 `ChatGPT` 的文字上沿，比悬在句尾或另加一条托线自然。整图生成也让猫、文字和留白从一开始就是同一个构图，不再出现后期拼贴感。

### IP 形象

长期母题仍是一只猫穿过聊天框，橙色尾尖作为识别点。封面这次不完整展示母标，而是让同一只黑猫自然趴在标题左上方。它保留炭黑轮廓、橙色耳朵和尾尖，但只作为标题旁的角色，不承担解释概念的任务。

### 删除测试

删除后，整篇会失去最强的停留理由，也没有猫猫老师第一次正式出现的视觉形象。

## 统一视觉约束

- 第 1 张为 1080×1440，3:4。
- 第 2 至 4 张保留用户原始截图尺寸与界面，不生成或复刻 ChatGPT UI。
- 封面不加入答案、方法清单、作者名、Logo、页码或系列名。
- IP 形象避免机器人、芯片、霓虹蓝、博士帽、眼镜、书本和普通猫爪 Logo。
- 270×360 缩略图下，封面可以完整读出标题；小猫能看出趴在第一行文字上，垂爪与橙色尾尖仍可识别。
- 发布前由用户再次确认截图侧栏、账号名称与其他任务名是否可以公开。
