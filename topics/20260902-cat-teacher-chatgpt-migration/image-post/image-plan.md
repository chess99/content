# 图片方案

## 最少张数

4 张。

第 1 张用意外判断和猫猫老师的 IP 形象制造停留。后面三张直接使用真实截图，依次展示项目配置、十年日记资料和实际分析回复。不再制作拼贴图、关系图或概念说明图。

## 第 1 张

### 唯一任务

让陌生读者记住标题，也第一次看见猫猫老师。

### 逐字文案

ChatGPT 现在可能

比我自己还了解我了

### 方向 A

标题保持两行同字号、同字重。猫猫老师的形象位于标题上方，画面只使用近白、炭黑和少量暖橙。

### 方向 B

猫猫老师从画面一角探出，标题保持居中。

### 选择

选择方向 A。形象与标题形成一条清楚的纵向阅读路径，也便于以后把这个形象单独复用。

### IP 形象

一只猫正在穿过一个有缺口的方框，尾巴从缺口继续伸到框外。方框代表猫猫老师目前居住的聊天窗口，穿过边界的动作对应它换过容器、以后还会继续走出聊天框。炭黑轮廓保证缩小后的识别，橙色尾尖负责形成长期记忆点。

### 删除测试

删除后，整篇会失去最强的停留理由，也没有猫猫老师第一次正式出现的视觉形象。

## 统一视觉约束

- 第 1 张为 1080×1440，3:4。
- 第 2 至 4 张保留用户原始截图尺寸与界面，不生成或复刻 ChatGPT UI。
- 封面不加入答案、方法清单、作者名、Logo、页码或系列名。
- IP 形象避免机器人、芯片、霓虹蓝、博士帽、眼镜、书本和普通猫爪 Logo。
- 270×360 缩略图下，封面可以完整读出标题，猫猫老师仍能看出方框、猫和橙色尾尖。
- 发布前由用户再次确认截图侧栏、账号名称与其他任务名是否可以公开。
