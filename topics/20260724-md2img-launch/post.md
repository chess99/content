# 做了个免费的 Markdown 转图片工具

最近我在让 AI 帮我测试量化策略，测试报告是 Markdown。

想跟朋友分享，直接扔一个 `.md` 文件肯定不合适；本地渲染再截图又有点麻烦。我就想找个小工具：Markdown 放进去，图片出来。

结果搜了一圈，几个能用的不是带水印，就是要订阅。

说实话，这种体量的小工具还要按月收费，我有点接受不了。尤其现在有 AI，自己做一个也就是顺手的事。

我把需求告诉 Codex，然后出去吃了个饭。

回来以后，已经能用了。

Markdown 实时预览、主题和尺寸调整、公式、Mermaid、PNG/JPEG/WebP/SVG/PDF 导出都有。所有内容都在浏览器本地处理，不上传服务器，也没有登录、次数限制、付费墙和水印。

我看了一眼，Codex 周额度还没花到 1%。
