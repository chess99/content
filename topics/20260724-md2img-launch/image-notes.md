# MD2IMG 发布素材说明

## 推荐顺序

1. `images/01-cover.png`
   - 首图，1200×1600。
   - 标题直接包含“免费 Markdown 转图片工具”。
   - 封面由 MD2IMG 自己生成，能形成一个自然的产品演示。

2. `images/02-workspace.png`
   - 展示编辑、预览和主题设置三栏工作台。
   - 发布时可在小红书内轻微裁掉上下空白，不要裁掉编辑区、预览区和主题卡片。

3. 建议补充：脱敏后的真实转换结果
   - 用一份虚构或脱敏的量化测试报告。
   - 最好做“Markdown 原文 → 导出长图”的对照。
   - 不展示策略参数、账户、收益明细、聊天对象或本地文件路径。

4. `images/04-codex-process.png`
   - 重点支撑“吃了个饭回来，工具已经能用了”。
   - 使用原始 Codex 长截图的完成记录制作，已排除参考网址、原始提示词和错误提交哈希。
   - 这张图不能证明“周额度不到 1%”；额度如需作为证据，另补真实额度截图。

5. `images/05-tests-and-deployment.png`
   - 证明项目不是只做了一个界面 Demo。
   - 展示 11/11 单元测试、三浏览器 15 项 E2E、生产构建和 40 个变更文件。

6. 建议补充：开源与使用入口
   - 等 GitHub 仓库公开后，截 README 首页或仓库主页。
   - 图片上同时放 `md2img.cearl.cc` 和 GitHub 仓库地址。
   - 如果加二维码，发布前用另一台手机实测。

## 现有横版素材

- `images/03-social-card.png` 是网站横版社交分享图。
- 适合 X、即刻、朋友圈或作为链接预览，不建议直接作为小红书首图。

## 最小可发布版本

如果暂时不补新素材，使用以下两张也可以发布：

1. `images/01-cover.png`
2. `images/02-workspace.png`
3. `images/04-codex-process.png`
4. `images/05-tests-and-deployment.png`

但如果目标之一是验证真实需求，建议至少再补一张“脱敏报告转换结果”。它比功能列表更容易让读者判断自己是否需要这个工具。
