## 标题

DeepSeek V4 Flash 到底什么水平？

## 正文

先说结论：**推荐用，但别把它当全能旗舰。**

DeepSeek 官方 API 现在已经更新到 `DeepSeek-V4-Flash-0731`。它最值得关注的不是“便宜版 V4”，而是把代码 Agent、工具调用和长上下文能力，压到了一个非常低的价格。

从定位看，它是一个 284B 总参数、每个 token 激活约 13B 参数的 MoE 模型，支持 100 万 token 上下文。注意，**13B 激活不等于普通 13B 小模型**：完整权重仍是数百 GB 级，本地部署并不轻松。

独立评测 Artificial Analysis 给 0731 版本的综合指数是 50，比 4 月版提高 10 分。这个成绩大致处在当前一线快模型附近，但仍落后于最强开放权重和闭源旗舰。

它最明显的强项是 Agent：

- GDPval-AA v2 从 1189 提升到 1559；
- Terminal-Bench 2.1 提升到 79%；
- 代码、终端、多步工具任务的进步，比单纯聊天更值得注意。

价格也确实夸张：官方 API 每 100 万 token，未缓存输入 0.14 美元、输出 0.28 美元；缓存命中输入只有 0.0028 美元。独立测试的输出速度约 113 token/s。

但它有几个不能忽略的短板：

1. **事实可靠性仍不是旗舰水平。** Artificial Analysis 的特定知识可靠性测试中，它的错误作答倾向依然较高。这个指标不等于“日常回答 84% 都错”，但说明遇到冷门事实、最新信息和高风险问题，必须配搜索与引用。
2. **它比较能写。** 单 token 很便宜，但推理模式输出量明显高于模型中位数，真实任务成本不会永远按标价比例下降。
3. **目前是文本模型。** 图片、视频和复杂视觉任务仍需搭配其他模型。
4. **100 万上下文不是 100 万 token 都能无损理解。** 大窗口很有用，但仍应该做检索、摘要和分层上下文。

所以我的使用建议是：

- 写代码、改仓库、跑终端 Agent：值得优先试；
- 批量任务、并行子 Agent、API 产品后端：很合适；
- 日常问答和长文整理：可以作为高性价比默认模型；
- 投资、医学、法律、新闻等事实密集任务：不能脱离搜索和人工核验；
- 普通个人电脑本地部署：不建议把它当“13B 模型”规划硬件。

更准确的定位不是“低价平替所有旗舰”，而是：

> **当前最值得尝试的低成本代码 Agent 模型之一。**

数据与价格口径截至 2026-08-04。独立评测采用特定推理强度和测试框架，不代表所有客户端开箱即得同样结果。
