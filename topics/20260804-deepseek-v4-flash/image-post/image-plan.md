# 五页图文轮播计划

统一规格：1080×1440，3:4。采用信息概要型图文：蓝白底、深蓝大字、少量亮蓝强调、清晰信息模块。封面和内页均不放 `晨笙做东西`、Logo 或品牌短句；可保留轻量栏目标签 `AI 模型` 和页码，作为导航而非品牌宣传。

## 读者问题

DeepSeek V4 Flash 到底值不值得用，适合交给它哪些任务？

## 一句话结论

推荐用，尤其适合代码和 Agent；但事实可靠性不是旗舰水平，不能无脑当权威。

## 最少卡片数

5 张。每张分别承担“总判断、能力档位、推荐理由、风险边界、行动建议”，没有过渡卡和研究过程卡。

## 01｜封面直接给概要

便宜、代码强，但别神化

- 代码 / Agent 很强
- 1M 上下文
- API 便宜得离谱

### 风险提示

但知识可靠性不是旗舰水平

### 视觉

- 信息卡优先，不做工艺装置、微缩工厂或品牌海报；
- 标题占据最强视觉层级，四个关键信息在手机缩略图下可扫读；
- 可用小型 AI 芯片或终端窗口作为辅助视觉，但不得抢过结论；
- 不放作者名、Logo 和系列品牌字标。

### 独立价值

只看到首图，读者也能获得完整的初步判断和点击理由。

## 02｜它是什么档位

### 标题

它大概是什么档位？

### 核心判断

- 开放模型第一梯队
- 全球大模型第二梯队上沿

### 三个限定

- 不是最强旗舰
- 也不是“便宜但凑合”
- 日常通用很强，极难任务仍有差距

### 底部总结

一句话：它已经很强，但还不是天花板。

### 口径

“第一梯队 / 第二梯队上沿”为基于当前公开规格与独立评测的作者综合判断，不是官方排名。完整数据见 `research.md`。

### 独立价值

回答“它究竟处在哪一档”，避免把价格低误解为能力弱，也避免把单项跑分写成全面登顶。

## 03｜为什么推荐它

### 核心句

我最推荐它做代码和 Agent。

### 四类任务

## 04｜但别神化

### 标题

但别神化：它的短板

### 四个边界

- 事实可靠性不是旗舰级
- 跑分不等于真实体验
- 13B 激活 ≠ 普通 13B 小模型
- 主要强在文本 / 代码，不是全能多模态

### 底部总结

适合拿来干活，不适合无脑当权威。

### 事实检查

- “13B”每次出现都必须带“激活”；
- 如补充参数，必须同页说明 284B 总参数；
- 不在卡片上突出“84%”等容易被误解的单项指标，详细限定留在正文和 `research.md`。

### 独立价值

阻止读者把推荐误读成“全面平替旗舰”，同时澄清本地部署和多模态误区。

## 制作与质检

- 5 张均以精确中文和信息层级为主，可使用确定性排版或“模型主视觉 + 确定性文字”的混合方式；
- 不因已有品牌资产强行加入作者名、Logo、系列名或品牌短句；
- 首图在 270×360 下能读出主题、副标题和至少两个关键点；
- 每张只保留一个核心问题，正文不逐字重复整张卡片；
- 精确参数、价格和独立评测数据逐项对照 `research.md`；
- 不使用 DeepSeek 官方 Logo 冒充官方合作素材；
- 每张脱离正文仍能读懂，但不重复上一张内容。
