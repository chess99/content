## 02｜先给结论

- 标题：推荐用，但不是全能旗舰
- 核心定位：当前最值得尝试的低成本代码 Agent 模型之一。
- 三个标签：一线快模型；Agent 强项明显；事实任务需验证。
- 视觉：中心是一枚“推荐”印章，左右分别放“适合做什么”和“别拿它做什么”，避免普通优缺点表格。

## 03｜它到底是什么模型

- 标题：13B 激活，不是 13B 小模型
- 关键数字：284B 总参数；约 13B 激活；1M 上下文；最大 384K 输出。
- 补充：MoE 每个 token 只调用部分专家，但完整权重仍需存储。
- 视觉：284 个专家模块组成大型机器，每次只点亮其中 13 个；用结构图解释“激活”和“总量”的区别。
- 脚注：参数来自 DeepSeek 官方与当前独立模型页；截至 2026-08-04。

## 04｜综合水平放在哪

- 标题：独立综合指数：50
- 对比：4 月版 40 → 0731 版 50；与 Gemini 3.6 Flash 同分；距 GLM-5.2 约 1 分；距 Kimi K3 约 7 分。
- 结论：进入一线快模型附近，但不是全球最强。
- 重要限定：Artificial Analysis Intelligence Index v4.1；Reasoning / Max Effort；2026-07-31。
- 视觉：纵向能力刻度尺，强调“位置”而非制作夸张领奖台。

## 05｜真正的强项是 Agent

- 标题：这次升级，主要强在干活
- 数据：GDPval-AA v2：1189 → 1559；Terminal-Bench 2.1：提升 17 个百分点至 79%；τ³-Banking：提升至 31%。
- 解释：仓库修改、终端操作、多步工具调用，比普通聊天更值得关注。
- 限定：不同 Agent Harness、提示词和推理强度会显著影响结果。
- 视觉：模型从“聊天框”走进终端、代码库和工具链，三段任务流水线共同指向已完成结果。

## 06｜价格为什么有吸引力

- 标题：价格低，但别只看单价
- 官方 API：未缓存输入 $0.14 / M；输出 $0.28 / M；缓存命中输入 $0.0028 / M。
- 独立测速：约 113.5 token/s。
- 隐藏成本：推理版输出约 210M token 完成整套指数，明显高于约 100M 的模型中位数。
- 结论：缓存、多任务和批量调用最划算；输出过长会吃掉一部分价格优势。
- 视觉：一边是极低单价标签，另一边是不断吐出的长纸带，形成“便宜 × 能写”的反差。

## 07｜三个容易踩的误区

- 标题：别被三个数字骗了
- 误区一：13B 激活 = 单卡可跑。纠正：完整模型 284B，原始 FP8 权重数百 GB 级。
- 误区二：1M 上下文 = 细节全记住。纠正：窗口规格不等于无损召回和推理。
- 误区三：综合 50 分 = 全面等于某旗舰。纠正：榜单是特定任务、Harness 和 Max 推理配置。
- 视觉：三个巨大的错误等号被红线划掉，下面分别放正确解释。

## 08｜真正的短板

- 标题：会做事，不代表什么都知道
- 事实可靠性：AA-Omniscience 特定测试中准确率约 37%，hallucination rate 约 84%；必须注明这不是日常回答错误率。
- 模态：文本输入、文本输出；视觉任务需其他模型代理。
- 版本：官方 API 当前为 0731；公开权重是否精确对应同一版本，部署前需再次核对。
- 结论：搜索、数据库、测试和人工确认仍然是必要组件。
- 视觉：模型高速执行任务，但事实卡片必须经过“搜索—引用—验证”三道门。

## 09｜怎么用最合理

- 标题：把它放在执行层，不是神谕层
- 推荐：代码 Agent；批量任务；并行子 Agent；API 后端；长仓库和长文档初步处理。
- 不建议单独承担：投资、医学、法律、新闻事实；视觉任务；不可逆全自动操作；普通电脑完整本地部署。
- 推荐架构：V4 Flash 执行 → 搜索/测试验证 → 难题升级更强模型 → 人工确认关键操作。
- 最终结论：低成本执行器，值得优先试；事实权威，不是。
- 互动问题：你更想拿它替换日常聊天模型，还是代码 Agent？
- 品牌短句：做出来，再讲明白。
