# 长鑫图文操作细节增强 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让读者在看完图文后明确知道何时观察、什么算强势、什么算转弱，以及500股如何分步处理。

**Architecture:** 保留现有四张图片和第一人称真实记录视角；重写发布正文，增加时间窗口、组合信号和仓位动作；新增一张与现有视觉一致的操作清单卡。

**Tech Stack:** Markdown 文案、Codex 内置 imagegen、PNG 位图

## Global Constraints

- 不写45元、60元等具体价格目标。
- 不承诺收益，不使用“应该买卖”等指令口吻。
- 所有动作写成作者本人针对500股的预案。
- 新增图片使用位图，不使用 SVG。
