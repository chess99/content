# 长鑫中签后怎么卖？我只看这3个信号

长鑫中签了，500股，申购款4330元。

这笔钱不影响日常生活，所以我不准备为了尽快回本而预设卖出价。最高点只能事后看到，我真正能提前准备的是：什么情况下继续拿，转弱以后卖多少。

一、上市首日前30分钟，不操作

科创板新股上市前5个交易日没有涨跌幅限制，开盘阶段主要是在做价格发现。无论高开多少，我都先看，不在前30分钟下单。

二、走势保持强势，500股继续持有

强势的标准是：还能持续创新高；回调后有资金快速承接，能重新站回开盘价和分时均价线；收盘仍接近日内高位。只要这些特征没有被连续破坏，我不会因为“已经涨很多”就卖出。

三、首次明确转弱，先卖200股

普通回调不算转弱，我会等组合信号：

1. 冲高明显回落：同时跌破开盘价和分时均价线，从日内高点回落约12%—15%，收盘远离最高价；
2. 放量却涨不动：放出上市以来的大成交量，却无法继续创新高，甚至收阴；
3. 调整后不能修复：收盘跌破前一个交易日最低价，或者次日仍站不回破位位置。

如果前两项同时出现，或者出现明显的爆量破位，我会先卖200股，留下300股观察修复。

四、次日仍不能修复，再卖剩余300股

如果第二天不能重新站回破位位置，或者继续下跌约5%以上，我会卖掉剩余300股。第一次异常可能是洗盘，连续异常更像趋势改变。

五、出现极端反转，不再分批

如果盘中一度大涨20%以上，随后翻绿收盘，同时出现爆量和巨大上影线，我会把仍持有的仓位全部退出；如果还是500股，就一次卖完。

这套方法会故意吐回一部分浮盈，换取参与主升段的机会。预案不是为了保证卖在最高点，而是避免临盘被情绪牵着走。

本人持有500股相关证券。以上仅为个人决策记录，不构成投资建议，不提供具体目标价或收益承诺。市场有风险，决策需独立。

你中签以后，更倾向首日落袋，还是给趋势一点时间？
