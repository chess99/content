# Superpowers 的流程税

- 创建日期：2026-07-22
- 主题：曾经被视为神级的 Agent skill，为什么在更通用、更强的智能体中开始显得多余
- 起因：Codex 在小红书文案任务中触发 Superpowers，并把非代码工作带入 TDD 流程
- 核心假设：
  1. Codex 的定位从代码开发工具扩展为通用智能体，旧的代码开发流程与实际任务发生错配。
  2. 模型能力进步后，一部分过去需要 skill 显式补足的能力已经被模型本身吸收。
