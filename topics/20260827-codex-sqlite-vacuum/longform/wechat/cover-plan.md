# 公众号封面方案

## 视觉判断

文章最值得呈现的关系不是某个软件 Logo，而是数据库从松散、空洞的 27GB 状态压紧到 742MB。封面使用左大右小的数据库页块：左侧带 C 盘告警，右侧完成压缩，中间保留清楚的流向。

## 最终规格

- 尺寸：900×383
- 格式：JPEG
- 原始成图：`source/cover-selected-raw.png`
- 发布文件：`cover.jpg`
- 正文：只保留 `27GB → 742MB`
- 色彩：深炭黑、告警红、冷蓝灰、回收后的青绿色
- 限制：不使用 OpenAI、Codex、Claude、Windows 或 SQLite Logo；不伪造软件截图；不加入作者名和品牌口号
