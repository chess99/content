# 别从零发明需求：独立开发者的「替代品」机会

- 主题状态：博客长文初版完成，待后续发布
- 首次立项：2026-08-26
- 主系列：工具与工作流
- 主要文体：行业分析
- 目标读者：寻找软件产品机会的独立开发者、AI Builder 和小团队
- 发布目的：把“做仿品”从简单复制产品重新定义为“承接已验证需求中的结构性逃逸”，给出可重复扫描、判断和验证的软件机会识别方法
- 核心判断：成熟软件已经替后来者完成了用户教育和需求验证。独立开发者真正值得复制的是被验证的需求，而不是原产品本身；好的替代品机会通常同时具备存量用户、明确逃逸理由和原厂难以顺手补齐的结构性切口。
- 风险等级：商业判断与产品机会
