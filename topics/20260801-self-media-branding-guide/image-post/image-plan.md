# 九页图文轮播计划

统一规格：1080×1440，3:4。首图按正式品牌规范整张模型生成；第 2—9 页使用确定性排版，事实与数字不交给图片模型。

## 01｜封面

- 系列：工具与工作流
- 主标题：自媒体品牌化 / 不是统一封面
- 可选短限定：从定位到测试，30天搭起来
- 唯一主视觉：一台真实材质的“品牌整理台”，左侧是形态各异的工具、数据、人物、猫内容卡，经过同一装置后仍保留不同主体，但出现统一的作者识别和信息层级。
- 目的：先反驳“品牌化 = 套模板”，制造点击理由。
- 生产：图片模型完整生成；不显示编号。

## 02｜先纠正一个误区

- 标题：你缺的不是统一模板
- 核心句：而是 3 个稳定答案
- 三问：谁做的？为什么值得关注？下一条还能得到什么？
- 视觉：三张巨大问题卡围绕一个中心“关注理由”，避免九宫格 PPT。

## 03｜我自己的小样本

- 标题：高赞题材 ≠ 立刻转型
- 数字：68 位粉丝；1908 次获赞与收藏；财经样本约 1003 / 241 赞；猫约 59；数篇 AI 工具为个位数。
- 结论：它说明财经解释值得继续测，不说明必须转纯财经。
- 限制：缺少曝光、进入率、主页访问和关注转化。
- 来源脚注：公开主页快照，2026-07-27。

## 04｜成熟账号统一的是什么

- 标题：他们固定的是识别锚点
- 五个样本：
  - 小岛大浪：颜色 + 印章 + 插画语言
  - 小Lin说：本人 + 巨大关键词
  - 老高與小茉：固定双人关系
  - 影视飓风：Tim + 巨大产品 + 短钩子
  - 蔡不菜：粉色 + 手绘 + 生活切片
- 结论：脸可以是锚点，但不是唯一答案。
- 口径：公开主页的编辑观察，不是效果实验。

## 05｜品牌系统的 5 层

- 标题：品牌不是一张 Logo
- 结构：身份锚点；关注承诺；栏目导航；视觉语法；数据复盘。
- 中心公式：被看见 → 被理解 → 被记住 → 被再次选择
- 视觉：五层实体轨道或阶梯，不画普通五边形。

## 06｜封面怎么统一又不无聊

- 标题：固定 5 件事，放开主视觉
- 固定：作者识别；栏目位置；字体层级；安全边距；一个证据点。
- 变化：一张脸 / 一个产品 / 一个数字 / 一个角色 / 一个强场景。
- 结论：成熟感来自相同语法下的变化，不是复制粘贴。

## 07｜别只盯着点击

- 标题：能点进来，还要接得住
- 个案数字：4.6% → 5.6%
- 说明：影视飓风频道自报，某类科技产品封面加入 Tim 拿产品后的个案；不是“露脸必涨 1%”。
- 官方原则：YouTube Test & Compare 以观看时长份额判断胜出，不只看 CTR。
- 迁移原则：封面承诺 × 首屏兑现 × 消费质量

## 08｜30 天行动表

- 标题：别先改旧帖，先跑一轮新样本
- 第 1 周：写一句关注理由；收进最多 3 个栏目。
- 第 2 周：准备三篇置顶；做 3 个封面方向。
- 第 3—4 周：发布 6—9 篇；每篇做 5 人 / 5 秒测试。
- 数据：24h / 7d / 30d 记录进入、收藏、分享、主页访问、关注转化和制作耗时。
- 限定：不重复发同一内容伪装 A/B。

## 09｜最后一张自检表

- 标题：你的账号能回答这 3 句吗？
- 自检：我是谁？为什么关注我？下一条大概还能得到什么？
- 结尾：品牌不是一次装修，是持续兑现。
- 互动问题：如果只能先改一项，你会先改定位、栏目，还是封面？
- 品牌短句：做出来，再讲明白。
