## 第 1 张：关键差异

### 作用

让读者在一张图内理解两家的关键倾向。采用分屏对照、中轴信号路径和品牌符号构成，信息量高于第二张。

### 文案

标题：

```text
Vercel 还是 Cloudflare？
看项目，不看站队
```

Vercel：

```text
Next.js 原生平台
完整 Node.js 支持更直接
更高的函数内存上限

常见场景
标准 Next.js / 完整 Node.js 依赖 / 服务端计算较重
```

Cloudflare：

```text
Workers 边缘运行环境
静态资源请求免费且不限量
R2 免互联网出口流量费

常见场景
静态资源多 / 动态逻辑轻 / 文件流量 / 多站
```

共同点与底部：

```text
轻后端、外部 API 调用，两边都能做
应用放 Vercel，文件放 R2，也可以
看项目，不看站队
信息核对：2026.08
```

### 证据

- Vercel Node.js Runtime、Functions Limits
- Cloudflare Workers Static Assets、R2 Pricing
