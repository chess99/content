# 图片模型 Logo 探索稿

四张 PNG 分别对应 [`identity.md`](../../../identity.md) 中的开框点、未完格、三束合流和晨笙信号。它们用于观察比例、气质和模型偶然产生的造型，不是可直接交付的生产 Logo。

| 文件 | 对应概念 | 主要风险 |
|---|---|---|
| `open-frame-ai.png` | 开框点 | 容易被理解成扫描框或相机取景框 |
| `open-grid-ai.png` | 未完格 | 容易像应用启动器 |
| `three-into-one-ai.png` | 三束合流 | 容易像 USB、路由或数据流图标 |
| `rising-reeds-ai.png` | 晨笙信号 | 容易像柱状图、行情或音频信号 |

选择时必须同时查看 `../logo-ai-vs-svg.*` 中的大图、32 px 头像和黑白判断。若模型位图的造型胜出，只对胜出的简单符号人工重建 SVG，并重新校正曲线、间距、单色版和最小尺寸；不要直接自动描摹并把大量噪声路径当作母稿。
