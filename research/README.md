# 跨主题调研

本目录保存不从属于某一篇待发布内容、可能被多个主题复用的过程性调研，包括账号策略、平台对标、热点扫描、行业研究和候选方案实验。

## 目录规则

- 每个调研项目使用 `YYYYMMDD-<slug>/`，日期取首次立项日期，后续更新不改目录名。
- 每个项目至少包含 `README.md`，记录创建日期、状态、目的、主要结论和转化去向。
- 原始资料、截图、实验稿和中间资产按需放入项目内的 `sources/`、`assets/` 等目录。
- 调研本身不等于准备发布的内容；需要发布时另建 `topics/YYYYMMDD-<slug>/`。
- 创作工作流不得自动读取本目录。结论只有提炼进入 `brand/` 或具体主题后才生效。
