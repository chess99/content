# 晨笙做东西｜封面策略与生产规范

本文件描述当前生效的封面决策方法。开始制作小红书图文首图或视频发布封面前，先读取 `BRAND.md`，再根据具体主题选择最有效的封面类型；不要从历史样例反推固定模板。

## 核心原则

封面首先是内容入口，不是品牌海报或设计作品集。

优先级为：

```text
主题可识别 → 结论清楚 → 点击理由充分 → 证据可信 → 视觉吸引 → 品牌装饰
```

- 作者名、Logo、系列名、品牌短句和编号默认都不是必选项。
- 用户本次要求和 `topic.md` 中的主题策略优先于本文件的默认建议。
- 不强制整张模型生图，也不禁止 SVG、HTML、Canvas、PPT 或其他确定性排版。
- 精确中文、参数、价格、排名、表格和结论应选择最可靠的制作方式，不把文字正确性寄托给图片模型。
- 封面可以直接给出实质性概要。尤其是模型测评、工具推荐、财经判断和教程，不必把结论藏到后续卡片。
- 如果“工艺品感”、概念场景或品牌装饰降低了阅读速度，立即改成更直接的信息表达。

## 先选择封面类型

### 1. 信息概要型

适合：模型测评、工具推荐、数据分析、财经判断、攻略和知识解释。

建议组成：

- 一个明确对象或问题；
- 一句结论；
- 2—4 个最有决策价值的事实、优点、限制或适用场景；
- 必要时补日期、口径或风险提示。

首图本身应有保存价值，读者只看到这一张也能得到一个有用判断。

### 2. 结果证据型

适合：产品发布、实测、改造前后、工作流成果和教程。

建议组成：真实成品、截图或对比结果 + 一句关键发现。不要用抽象场景替代真正的结果。

### 3. 人物主体型

适合：个人表达、访谈、人设内容、真人体验和角色账号。

稳定人物、表情、动作或标志性卡通角色可以承担品牌识别；不必再叠加 Logo。

### 4. 场景情绪型

适合：猫、摄影、故事、AI 影像和作品发布。

保留一个强场景或动作，文字只负责说明冲突、情绪或结果，不把画面压成信息表格。

### 5. 品牌海报型

只在以下情况使用：品牌本身已成为点击理由、活动或系列发布需要正式感，或者用户明确要求。小账号日常内容默认不采用。

## 品牌识别怎么放

品牌识别可以由下列任意两三项形成，不要求全部出现：

- 稳定配色；
- 标题层级和网格；
- 栏目小标签；
- 真人或固定角色；
- 图标与插画语言；
- 一贯的判断方式和语气；
- 作者名或 Logo。

`晨笙做东西`、`晨笙信号` 和系列名仅在确有识别或导航价值时使用。若它们与主题争夺注意力，优先删除。

## 生产方式

根据内容选择，不设唯一正确路线：

| 方式 | 优先场景 | 注意事项 |
|---|---|---|
| 确定性排版 | 中文标题、信息卡、参数、数据、表格、对比 | 逐项核对文字和数字；避免普通 PPT 的机械堆框 |
| 截图/摄影/真实素材 | 产品、过程、结果、实测 | 保护隐私；用标注突出证据，不伪造 UI |
| 图片模型 | 人物、角色、氛围、概念场景、强主视觉 | 不把模型生成的小字和数字当事实 |
| 混合制作 | 既要主视觉又要精确信息 | 可以先生成主视觉，再用确定性工具排版文字与数据 |

图片模型不可用时，不构成封面制作阻塞；应改用适合当前内容的其他方式。

## 信息概要型提示骨架

```text
制作一张 3:4 竖版社交媒体信息封面，最终尺寸 1080×1440。

主题：[对象或读者问题]
核心结论：[一句话判断]
关键信息：[2—4 个最有价值的事实、适用场景或限制]
必要口径：[日期、数据范围或风险提示]

要求：
- 在 270×360 缩略图下 5 秒内能看懂主题和结论；
- 标题、结论和关键信息层级明显；
- 不添加作者名、Logo、系列名、口号或页码，除非本次明确要求；
- 不使用与主题无关的工艺品场景、品牌海报感或复杂装饰；
- 精确中文和数字必须可核对。
```

## 人物或场景型提示骨架

```text
制作一张 3:4 竖版社交媒体封面。

主题：[主题]
唯一主体：[人物、角色、猫、作品或强场景]
核心动作/冲突：[动作、反差或结果]
必要标题：[尽量短]

要求：
- 主体在缩略图下清晰；
- 文字不盖住脸、动作或作品关键区域；
- 不自动添加作者名、Logo、系列名、编号和水印；
- 画面服务内容本体，不做无关的企业宣传物料。
```

## 精确性边界

- 模型生成的 UI、图表、票据、按钮、小字和数字不构成证据。
- 封面直接宣称的关键数字必须能追溯到 `research.md` 或原始来源，并逐字核对。
- 真实产品截图、可复核图表和来源优先直接使用，不必为了“统一风格”重新生成。
- 人物和角色检查身份连续性、成年感、五官、手部和服装；AI 角色内容保留必要的 AI 生成标注。

## 选择与质检

需要候选时生成或制作 2—3 个真正不同的方向，例如：结论型、问题型、结果证据型。不要只换颜色和装饰。

选定前检查：

1. 270×360 下能否在 5 秒内说出“讲什么”和“结论是什么”。
2. 首图是否已经给出至少一个有用判断，而不只是悬念。
3. 品牌元素删除后是否更清楚；若是，就删除。
4. 有没有 2—4 个真正提高点击或收藏价值的信息点，而不是小字堆积。
5. 事实性标题、数字、日期和产品界面是否准确。
6. 是否存在概念主视觉很精致，但读者不知道为什么要点的问题。
7. 封面承诺是否能由后续卡片和正文兑现。

## 历史参考

`assets/cover/references/` 保存历史视觉方向，只可参考材质、构图或信息层级，不代表当前必须继续使用工艺装置、Logo、作者字标或整张模型生图。

最终封面保存到具体主题的 `image-post/images/` 或 `video/publish/`，不要把主题产物写回本目录。
