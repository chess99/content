# 正式品牌资产

本目录只保存“晨笙做东西”当前正式生效、允许创作工作流直接使用的干净品牌规则与资产。

- `BRAND.md`：长文、图文和视频工作流默认读取的唯一品牌入口。
- `COVER.md`：完整模型生图的封面生产规范、提示骨架和质检门禁。
- `PROFILE.md`：需要本人在平台手动设置的显示名、头像和简介。
- `assets/logo/`：模型造型参考，以及非封面场景使用的精确 Logo 资产。
- `assets/cover/references/`：正式封面风格参考图，不是可替换文字的模板。

品牌讨论、命名过程、对标研究、候选 Logo、SVG 封面和对照稿保存在根目录 `research/YYYYMMDD-<slug>/`。工作流不得自动读取调研目录；只有被人工确认并写入 `BRAND.md`、`COVER.md` 或列入正式资产的结论才生效。

具体主题的最终封面仍放在对应的 `TOPIC_DIR/image-post/images/` 或 `TOPIC_DIR/video/publish/`。通用工作流和生产工具位于 `D:\code\content-studio`。
