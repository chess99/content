# 正式品牌资产

本目录只保存“晨笙做东西”当前正式生效、允许创作工作流直接使用的规则与资产。

- `BRAND.md`：长文、图文和视频工作流默认读取的唯一品牌入口。
- `PROFILE.md`：需要本人在平台手动设置的显示名、头像和简介。
- `assets/logo/`：可选 Logo 资产。只有确实提升识别、信任或导航时才使用。

本目录不保存固定封面规范、封面模板、参考封面、栏目配色或历史视觉样例。相关实验留在根目录 `research/YYYYMMDD-<slug>/`，工作流不得自动读取。

具体主题的图片和视频发布资产放在对应 `TOPIC_DIR`。通用工作流和生产工具位于 `D:\code\content-studio`。
