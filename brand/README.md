# 正式品牌资产

本目录只保存“晨笙做东西”当前正式生效、允许创作工作流直接使用的品牌规则与资产。

- `BRAND.md`：长文、图文和视频工作流默认读取的唯一品牌提示。
- `assets/`：仅在 Logo、头像或模板正式定稿后创建；候选方案和实验稿不得放入。

品牌讨论、命名过程、对标研究、候选 Logo 和封面对照稿保存在根目录 `research/YYYYMMDD-<slug>/`。工作流不得自动读取调研目录；只有被人工确认并写入 `BRAND.md` 或列入正式资产的结论才生效。

具体主题使用的最终封面仍放在对应的 `TOPIC_DIR/image-post/images/` 或 `TOPIC_DIR/video/publish/`。通用工作流和渲染工具位于 `D:\code\content-studio`。
