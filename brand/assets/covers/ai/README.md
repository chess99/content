# 图片模型封面探索稿

这里保存图片模型直接生成的完整封面原稿，用于和 `../deterministic/` 中的 SVG 方案比较。它们是构图探索和品牌样例，不是已经通过事实、文字与安全检查的发布文件。

## 文件与输入

| 文件 | 参考素材 | 主要构图任务 |
|---|---|---|
| `md2img-ai.png` | 已发布封面、真实产品界面、开框点 Logo | 将 Markdown 原稿与长图输出做成一台编辑排版机器 |
| `a-share-valuation-ai.png` | A 股视频旧封面、开框点 Logo | 将“接近 80%”做成透明测量仪与历史曲线 |
| `content-workflow-ai.png` | 开框点 Logo | 将内容流程做成桌面微缩工厂 |
| `lin-zhaowan-ai.png` | 海边主图、角色参考图、开框点 Logo | 保持角色身份并重构电影感海边海报 |

四张原图均为模型输出的约 3:4 位图，主标题、栏目与证据条在提示中被明确指定。比较时使用同题 SVG 中尽量相同的标题和证据，不把文案优劣误当成制作方式优劣。

## 发布门禁

- 逐字检查标题、栏目、Logo、证据条和图片中的所有可见小字；
- 产品界面用真实截图覆盖，不能发布模型想象的按钮或功能；
- 财经折线、年份、峰值和当前数据必须用真实数据重绘；
- 流程节点必须与实际工作流一致，删除模型自行增加的工位；
- 角色图检查成年感、五官、发型、服装和气质连续性，并保留 AI 生成标注；
- 胜出的模型图保留主视觉与空间关系，关键中文、Logo、真实 UI 和数据用确定性图层覆盖。

不要覆盖这些原始 PNG。发布级混合版应另存到对应 `TOPIC_DIR`。
