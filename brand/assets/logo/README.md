# 正式 Logo

“晨笙信号”由三根弧形笙管/信号柱与一颗晨光圆点组成。它同时承接名字、数据与创作节奏，但不解释成股票柱状图。

- `mark.svg`：默认彩色图形标，透明背景。
- `mark-mono.svg`：印章、小尺寸单色输出。
- `mark-reverse.svg`：深色背景使用。
- `lockup-horizontal.svg`：浅色背景横向组合。
- `lockup-horizontal-reverse.svg`：深色背景横向组合。
- 同名 PNG：便于不支持 SVG 的平台直接使用。

不要旋转、描边、加投影、改变比例或按栏目换色。最小尺寸 24 px；小于 40 px 只使用图形标。
