# 母品牌视觉识别探索 v0.1

**日期**：2026-07-27
**状态**：探索稿；账号全名与最终 Logo 均尚未选择，当前生效状态见 `BRAND.md`。

## 1. 设计目标

母品牌需要同时容纳“工具与工作流”“数据与财经”“创作实验”，不能继承某一篇财经作品的临时视觉，也不能因账号改名而整体推倒重做。

本轮把识别系统拆成两层：

1. **名称无关的母品牌符号**：可用于头像、封面角标、视频片尾和水印；
2. **可替换的中文标准字**：账号名确定后再与符号组合，不把 `Cearl`、`晨`、`笙`等字符提前焊死在图形里。

Logo 只是小而稳定的识别锚点。主页是否形成品牌感，主要仍取决于标题字体、网格、边距、栏目标签、图片处理和片尾签名能否高频重复。

## 2. 共同约束

- 图形必须能脱离文字独立成立；图片模型不承担中文标准字生成。
- 16—32 px 仍能辨认，黑白版不依赖颜色解释结构。
- 不使用机器人、芯片、脑、线路板、通用 AI 星芒等短周期符号。
- 不把股票 K 线、货币符号或财经红绿涨跌做成母品牌图形。
- 母标保持稳定；三个栏目用标签和辅助色区分，不各自另造 Logo。
- 头像优先保留真人照片时，Logo 作为封面角标、片尾和水印；确定长期不出镜后再评估用 Logo 替换头像。

## 3. 四个方向

| 顺序 | 方向 | 核心含义 | 名称依赖 | 当前判断 |
|---|---|---|---|---|
| 1 | 开框点 / Open Frame | 从复杂世界中框定问题，以证据或作品给出结果 | 无 | 决赛一；AI 连续轮廓优于当前分离角 SVG |
| 2 | 未完格 / Open Grid | 三类现有内容与一个持续出现的新实验 | 无 | 模型版有手感，但应用启动器既视感仍强 |
| 3 | 三束合流 / Three Into One | 多种输入经过同一方法，形成清晰输出 | 无 | 更适合动效语言，不作为首选头像 |
| 4 | 晨笙信号 / Rising Reeds | 晨光、笙管、数据柱和数字信号 | 较强 | 决赛二；若启用“晨笙”，按 AI 弧形轮廓精修 |

### 3.1 开框点

三个圆角角标组成未闭合的编辑框，偏心圆点代表证据、灵感或成品。缺失的右上角给未来题材留出空间。

- 优点：名称无关，能覆盖工具、财经、角色和作品；很容易形成“框选—聚焦—展开”的动态片头。
- 风险：画得过细或四角过于对称时，会像相机对焦框。
- 修正：只保留三个角，采用粗圆头，并让圆点略向开放方向偏移。

### 3.2 未完格

2×2 网格中保留三个不完全等大的圆角方块，第四格由圆点替代。方块代表结构化成果，圆点代表下一次实验。

- 优点：能把“内容杂”重新解释为同一实验室里的不同格子；还可外延为封面网格语言。
- 风险：等大等距时容易像应用启动器或办公软件图标。
- 修正：使用非对称尺寸、不同圆角和方圆对比，不使用四个等大模块。

### 3.3 三束合流

三条轨道从左侧进入，在中部汇聚成一条稳定输出。表达“不同题材，共用一套做出来再讲明白的方法”。

- 优点：运动感最强，适合视频转场和栏目汇聚动画。
- 风险：交汇处处理不好会像分享、路由或 USB 图标；小尺寸容易发黑。
- 修正：不加箭头，输出使用平直光束；16 px 版本需要将交汇处转轮廓后人工减重。

### 3.4 晨笙信号

三根高低不同的圆头竖柱同时指向笙管、数据柱、信号和创作节奏，右上圆点代表晨光。

- 优点：如果中文名保留“晨笙”，名称与视觉故事最完整。
- 风险：改名后解释力下降，也可能被误认为行情或音频应用。
- 修正：名称确定前不投入深度定制；避免刻度、基线和等间距柱状图语法。

## 4. v0.1 色彩

以下颜色用于比较稿，不等于最终品牌定色：

| 角色 | 色值 | 用途 |
|---|---|---|
| 墨黑 | `#17191C` | 主轮廓、黑白母标 |
| 暖纸白 | `#F7F3EA` | 资产预览和封面底色 |
| 电光蓝 | `#315CFF` | 开框点强调色、数字工具感 |
| 活力珊瑚 | `#FF5B4D` | 未完格与晨光强调色 |
| 深靛蓝 | `#172554` | 晨笙信号主体 |

栏目辅助色继续由账号策略控制。即使栏目切换，最终母品牌 Logo 也不应在蓝、红、紫之间随意换色；颜色导航放在栏目标签、关键词、数字或细线中。

## 5. 字标与组合方式

名称确定前只维护图形标。确定后再制作以下组合：

- **横向组合**：图形标 + 中文账号名，适合视频片尾和来源卡；
- **竖向组合**：图形标在上、中文账号名在下，适合头像之外的品牌页；
- **纯图形**：适合头像、封面角标和小水印；
- **英文辅助字**：仅在确有传播价值时使用，不默认保留生僻英文名。

字标初测可使用思源黑体 Heavy 或 HarmonyOS Sans SC Bold。符号与中文名之间保留约 `0.35×` 符号高度的间距，不让字体风格压过图形。

## 6. 最小使用规则

- 最小建议尺寸：屏幕显示 `16 px`；常规封面角标 `24—40 px`；视频片尾 `64 px` 以上。
- 安全留白：图形四周至少保留圆点直径或主笔画宽度的 `1.5×`。
- 黑白印刷：所有强调色统一替换为纯黑；深色背景统一替换为纯白。
- 复杂照片上不得直接裸放彩色标，应使用暖白或墨黑的小型承载底块。
- Logo 不充当标题标点，不旋转、不描边、不加投影、不做金属或玻璃质感。
- 对 Logo 而言，生成式位图用于造型探索；胜出符号应回到可复现的 SVG 几何母稿。封面中的摄影式 AI 主视觉可保留为位图，不适用这条规则。
